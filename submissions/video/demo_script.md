## Title

Replayable Harnesses for Stateful Agent Contracts

## Description

This demo shows a small reproducible harness for evaluating stateful AI agents
through tool-call traces, permission gates, state diffs, replay records, and
regenerated result tables. The artifact accompanies the paper "Thin Harness,
Strong Contracts: Production-Oriented Agent Harnesses for Stateful AI Agents."

Repository: https://github.com/rrrrrredy/agent-harness-paper

Archive: https://doi.org/10.5281/zenodo.20907471

## Scenes

1. Problem: final answers hide operational failures.
2. Artifact map: benchmark cases, harness code, raw runs, regenerated results,
   and reviewer docs.
3. Contract anatomy: task, allowed tools, forbidden tools, state assertions,
   replay record.
4. Run validation: `python scripts/run_checks.py --mode validate`.
5. Inspect a security or permission case.
6. Regenerate tables and compare prompt variants.
7. Review packaging: GitHub, Zenodo, licenses, release tag.
8. Closing: thin around cognition, strong at system boundaries.
