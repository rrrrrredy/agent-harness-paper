# Reviewer Guide

This repository is an artifact package for the paper:

**Thin Harness, Strong Contracts: Production-Oriented Agent Harnesses for Stateful AI Agents**

## What To Read First

1. `paper/main.tex` for the manuscript.
2. `artifact_manifest.json` for the artifact map.
3. `experiments/run_manifest.md` for what was run and what was not.
4. `docs/claim_boundaries.md` for permitted and excluded claims.
5. `docs/experiment_protocol.md` for metrics, providers, variants, and regeneration commands.

## Result Sources

Reported pilot metrics come from raw JSONL files under `experiments/raw/` and are regenerated by `scripts/analyze_results.py`.

Primary result tables:

- `results/tables/experiment_summary.md`
- `results/tables/category_summary.md`
- `results/tables/failure_taxonomy.md`
- `results/tables/failure_inspection.md`

The PDF workflow uses the TeX tables in the same directory.

## Evidence Boundaries

`evidence/github_snapshots.md` identifies first-party repositories and upstream PR metadata. `evidence/source_audit.md` adds path-level and keyword-signal evidence without storing source bodies. These artifacts support bounded case-study interpretation; they do not prove runtime behavior by themselves.

## Validation

Use the local virtual environment if present:

```powershell
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python scripts\check_tex_sources.py
.\.venv\Scripts\python scripts\check_public_traces.py
.\.venv\Scripts\python scripts\secret_scan.py
```

Regenerate derived tables:

```powershell
.\.venv\Scripts\python scripts\backfill_run_metadata.py
.\.venv\Scripts\python scripts\analyze_results.py
.\.venv\Scripts\python scripts\inspect_failures.py
.\.venv\Scripts\python scripts\generate_figures.py
```

Live provider reruns require valid provider credentials in environment variables. Missing or invalid credentials should remain recorded as provider failures rather than replaced with invented measurements.
